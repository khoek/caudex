# caudex

A repository housing various useful Rust libraries.

- `calculo`: pluggable numeric traits for exact and approximate arithmetic
- `capulus`: shared support for polished, robust command-line tools
- `clikeys`: namespace-aware `KEY=VALUE` overrides for nested configuration structs
- `clikeys-derive`: derive macros for `clikeys` configuration structs
- `syntheon`: build-script utilities for downloading, unpacking, and staging vendored source archives
